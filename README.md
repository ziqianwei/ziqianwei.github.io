# Ziqian Wei

Personal notes site built with Hugo.

## Structure

- Knowledge
- Papers
- Books
- About

## Publishing

The site includes Decap CMS at `/admin/`. Its editor is configured to write Markdown directly into this repository.

GitHub authentication for Decap requires a one-time OAuth/auth provider setup. Until that is configured, posts can also be added by creating Markdown files in the corresponding `content/` folder.

## Local preview

```bash
hugo server -D
```
